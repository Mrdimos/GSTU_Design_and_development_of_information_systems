# Лабораторная работа № 2. CLI-утилита и автоматизация корпоративных операций

> Общие правила, таблица вариантов, соглашения по данным/API и шкала оценивания: [`Общие_указания.md`](Общие_указания.md).

**Трудоёмкость:** 2 академических часа.  
**Цель:** Создать консольную утилиту для выполнения одной полезной операции над данными выбранной предметной области.  
**Основные понятия:** process.argv, process.env, process.exitCode, console, path, fs/promises, коды завершения, конфигурация и проверка аргументов.

### Теоретическая справка

CLI (command-line interface) автоматизирует операции без графического интерфейса. process.argv содержит аргументы запуска, process.env — настройки окружения, а process.exitCode позволяет сообщить вызывающей системе об ошибке. Модуль path помогает строить переносимые пути. Файловые операции асинхронно выполняются через fs/promises. Надёжная утилита валидирует ввод, выводит понятные сообщения и не раскрывает конфиденциальные данные.

### Индивидуальное задание

Выполните общий алгоритм ниже, а предметную логику возьмите из строки своего варианта в таблице «Индивидуальные требования по вариантам» для этой лабораторной. Не заменяйте индивидуальное требование универсальным примером.

**Обязательный минимум:** все пронумерованные пункты этого раздела, кроме явно перенесённых в «Углублённую часть».

1. Добавить отдельную команду npm run cli -- <команда> [параметры].
2. Реализовать минимум две операции: например, list/report и validate/import; точные операции определяются вариантом.
3. Использовать process.argv для аргументов, path для формирования путей и fs/promises для чтения/записи файла.
4. Проверять наличие обязательных аргументов и корректность входного JSON/CSV (CSV можно реализовать упрощённо с явно описанными ограничениями).
5. Считать конфигурацию из переменных окружения, задать безопасные значения по умолчанию; не хранить пароли и токены в коде.
6. Выводить понятные сообщения в stdout/stderr и устанавливать ненулевой process.exitCode при ошибке.
7. Проверить нормальный сценарий, пустой файл, неверный аргумент и некорректные данные.
