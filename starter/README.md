# Стартовый каркас студенческого проекта

1. Скопируйте `.env.example` в `.env` и замените фиктивные секреты. Не добавляйте `.env` в Git.
2. Установите подходящую LTS-версию Node.js и npm.
3. Выполните `npm install`, затем храните созданный lockfile и используйте `npm ci` для воспроизводимой установки.
4. `npm test` запускает встроенный `node:test`; `npm run check` проверяет синтаксис сервера.
5. `examples/redis-session.js` — пример middleware для Redis; `examples/openapi.yaml` — стартовая OpenAPI-спецификация; `examples/socket-client.js` — минимальный клиент Socket.IO.
6. Для SQLite включайте `PRAGMA foreign_keys = ON` при каждом открытии соединения.

Это каркас, а не готовая реализация лабораторных: добавьте предметную модель своего варианта, миграции, репозитории, middleware, тесты и README с точными версиями библиотек.

## Скелет SQL-репозитория для ЛР6

- `src/db.js` открывает SQLite и включает `PRAGMA foreign_keys = ON` на каждом соединении.
- `src/repositories/entityRepository.js` показывает разделение SQL и контроллера. Создайте таблицу `entities` либо замените пример своей предметной таблицей; добавьте миграции и тест нарушения FK.
